# Пальне.UA — автооновлюваний трекер цін

Дашборд цін на пальне по 10 мережах АЗС України, який **сам** оновлюється
раз на добу через GitHub Actions — без ручного втручання.

## Як розгорнути (5 хвилин)

1. Зайди на github.com → **New repository** → назви, наприклад, `fuel-ukraine` → Create.
2. Завантаж у нього всі файли з цієї папки, зберігаючи структуру:
   ```
   fuel-ukraine/
   ├── .github/workflows/update-prices.yml
   ├── scripts/scrape_prices.py
   ├── index.html
   └── README.md
   ```
   (Можна просто перетягнути папку через "Add file → Upload files" на GitHub,
   або через `git push`, якщо звичний до консолі.)
3. Перейди в **Settings → Actions → General → Workflow permissions** і вибери
   **"Read and write permissions"** — інакше боту нічим буде комітити оновлений `prices.json`.
4. Перейди в **Actions** → знайди workflow "Update fuel prices" → **Run workflow**
   (запусти вручну перший раз, не чекаючи на 06:00).
5. Після того як workflow відпрацює (1-2 хв), у репозиторії з'явиться `prices.json`.
6. Увімкни сторінку: **Settings → Pages → Source: Deploy from branch → main → / (root)**.
7. Через хвилину сайт буде доступний на `https://<твій-нікнейм>.github.io/fuel-ukraine/`.

Далі все відбувається саме: щодня о 06:00 за Києвом Actions заходить на
сайти-джерела, оновлює `prices.json`, а `index.html` показує свіжі цифри.

## Якщо мережа показує "н/д"

Це означає, що сайт-джерело (index.minfin.com.ua) змінив верстку сторінки,
і скрипт не може знайти ціну за старим шаблоном. Що робити:

1. Відкрий проблемну сторінку в браузері (посилання — в `NETWORKS` у
   `scripts/scrape_prices.py`).
2. Права кнопка миші на таблиці цін → "Переглянути код" (Inspect).
3. Онови функцію `parse_operator_page()` під нову структуру HTML.
4. Заплануй запуск через **Actions → Run workflow**, щоб перевірити виправлення.

## Обмеження

- Джерело — лише index.minfin.com.ua. Якщо сайт заблокує автоматичні запити
  (rate-limit), потрібно буде або рідше запускати cron, або додати інше джерело.
- Оптові (гуртові) ціни в цьому трекері не збираються — вони формуються не
  по роздрібних мережах, а по трейдерах/біржі (УЕБ), і публікуються окремо.
- GitHub Actions cron може запускатись із затримкою в кілька хвилин —
  це нормальна поведінка безкоштовних раннерів GitHub.
